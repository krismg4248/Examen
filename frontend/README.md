# TORQUE — Frontend

Svelte + Vite + Tailwind CSS + Three.js.

## Arranque

```bash
cd frontend
npm install
npm run dev
```

Abre `http://localhost:5173` (el proxy envia `/api` al backend en el puerto 3000).

## Rutas

| Ruta | Descripcion |
|---|---|
| `/#/` | Login |
| `/#/registro` | Registro (rol empleado) |
| `/#/panel` | Catalogo de piezas (sesion requerida) |
